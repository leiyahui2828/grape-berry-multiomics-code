# Required local helper files

Copy the exact historical versions used in the analysis:

```text
software/batmeth2merge.R
software/run_DM_analysis.R
```

The differential methylation workflow also requires the original:

```text
samples_info.txt
contrasts.txt
```

The historical pipeline used:

```text
sifs/methtools20220515.sif
```

Do not upload the large `.sif` image to GitHub. Record the versions of Bismark,
BatMeth2 and other software contained in that image instead.
